# AI Disclosure & Methodological Transparency

## Ethical Statement on AI-Assisted Code Generation

This repository, **A.T.H.E.N.A.** (Adaptive Telemetry, Health, and Evidence-Based Nutrition Analytics), was developed with extensive assistance from free and publicly available Artificial Intelligence coding assistants (including Large Language Models such as Google Gemini, Claude, and OpenAI ChatGPT).

> **The author is a sports science researcher, NOT a software engineer. This repository demonstrates domain knowledge translation and AI orchestration. The code is provided "as is".**

---

## Authorship & Role Delineation

1. **Domain Logic & Scientific Architecture (Human):**
   - Identification, curation, and mathematical formulation of clinical sports science models:
     - International Olympic Committee (IOC) Consensus on Relative Energy Deficiency in Sport (RED-S; Mountjoy et al., 2018, 2023).
     - Acute:Chronic Workload Ratio (ACWR; Gabbett, 2016; Hulin et al., 2016) with exponential weighted moving averages.
     - Dual-Threshold Blood Lactate Turnpoint Dynamics (LT1 / LT2; Faude et al., 2009).
     - Multi-stage Sleep Architecture (AASM criteria) & nocturnal autonomic cardiac metrics (HRV / rMSSD).
     - Female Athlete Triad cumulative risk scoring (De Souza et al., 2014).
   - Prompt engineering, iteration, and algorithmic direction.
   - Independent verification of calculated metrics against established peer-reviewed physiological ranges.

2. **Code Generation & Implementation (AI Coding Assistants):**
   - Boilerplate scaffolding in Python (FastAPI, NumPy, Pandas, SQLite) and R Shiny (HTML, CSS, Bootstrap, Plotly).
   - Syntax debugging, containerization scripts (Docker, docker-compose), and cross-platform automation scripts (Bash, Batch).
   - Localization dictionary generation across multiple languages.

## Intent and Academic Scope

This project represents an **exploratory academic prototype** demonstrating how an applied domain specialist (in sports biomechanics and exercise physiology) can leverage generative AI tools to translate complex clinical decision algorithms into interactive digital dashboards. 

It is **NOT** intended to represent:
- Formal, professional software engineering practices.
- Production-grade medical device software (SaMD).
- Fully certified commercial sports analytics infrastructure.
