# Contributor AI Policy

## Transparency in AI-Assisted Contributions

A.T.H.E.N.A. embraces modern technological tools, including AI coding assistants (e.g., GitHub Copilot, ChatGPT, Claude, Gemini, Cursor). However, to protect the legal integrity, quality, and licensing posture of the project, all contributors must adhere to this **AI Contribution Policy**.

---

## 1. Mandatory Disclosure

If any part of your Pull Request (PR) contains code, documentation, mathematical formulation, or scripts generated or co-authored with an AI tool, **you must explicitly disclose this in your Pull Request description**.

Your PR template should include:
- [ ] **AI Disclosure:** Did you use an AI tool to generate code in this PR? (Yes / No)
- **Tool(s) Used:** (e.g., Claude 3.7 Sonnet, OpenAI o3, Gemini Pro, GitHub Copilot)
- **Scope of Generation:** (e.g., "Generated unit tests", "Scaffolded CSS styling", "Translated docstrings")

---

## 2. Verification of Rights to Submit

Before submitting AI-generated code to A.T.H.E.N.A., you must verify that:
1. The terms of service of the AI tool allow commercial use and sublicensing of its output.
2. The AI tool did not emit plagiarized or copyrighted code snippets subject to restrictive licenses (e.g., GPL code ingested into non-permissive contexts) without proper attribution.
3. You have reviewed, understood, and tested every line of code submitted. **Do not submit unverified "hallucinated" code or dependencies.**
4. You possess the full legal authority to grant the project owner the license rights specified in [CLA.md](CLA.md).

---

## 3. Human Responsibility

AI tools cannot be held legally or scientifically accountable. As the submitting contributor, **you remain personally responsible for the correctness, safety, and licensing compliance of your submission**.

Unverified, raw AI dumps that have not been manually validated for sports science correctness or code functionality will be closed without merge.
